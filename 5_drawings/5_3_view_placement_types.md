# 5.3. Drawing View Placement and Types in SolidWorks API (C#)

This section details how to programmatically insert and place drawing views of various types (standard base, projected, section, detail, and auxiliary views) onto active drawing sheets.

---

## 📐 Coordinates in Drawing Space

All placement coordinates (`X`, `Y`, `Z`) used in drawing view methods are measured in **meters** relative to the bottom-left corner of the active sheet. 

> [!TIP]
> When layout designing, convert sheets values in millimeters to meters:
> `X_meters = X_mm / 1000.0`

---

## 💻 C# Code: Creating Base and Projected Views

The base view is the primary projection inserted onto a sheet. Other views (projected, section, detail) depend on this base view.

```csharp
using System;
using SolidWorks.Interop.sldworks;
using SolidWorks.Interop.swconst;

public class ViewPlacementManager
{
    public void CreateStandardViews(IDrawingDoc drawing, string modelPath)
    {
        IModelDoc2 model = (IModelDoc2)drawing;
        
        // 1. Insert Base view (Front View orientation) at (100mm, 150mm)
        // ViewName syntax: "*Front", "*Top", "*Right", "*Isometric"
        double baseLocX = 0.1; 
        double baseLocY = 0.15;
        
        IView baseView = drawing.CreateDrawViewFromModelView3(
            modelPath, 
            "*Front", // Standard view orientation name
            baseLocX, 
            baseLocY, 
            0.0
        );

        if (baseView == null)
        {
            Console.WriteLine("Failed to create Base view.");
            return;
        }

        baseView.SetName2("FrontView");
        Console.WriteLine("Base Front View created.");

        // 2. Select the newly created base view to prepare for projection
        model.ClearSelection2(true);
        bool viewSelected = model.Extension.SelectByID2("FrontView", "DRAWINGVIEW", 0, 0, 0, false, 0, null, 0);

        if (viewSelected)
        {
            // 3. Create a Projected View (Top View projection placed at X=100mm, Y=250mm)
            IView projectedView = drawing.CreateProjectedView2(0.1, 0.25, 0.0);
            
            if (projectedView != null)
            {
                projectedView.SetName2("TopView");
                Console.WriteLine("Projected Top View created.");
            }
        }
        
        model.ForceRebuild3(false);
    }
}
```

## 📍 Creating Section Views (CreateSectionViewAt5)

Inserting a section view requires drawing a section line segment inside the parent view sketch before invoking the section view method.

```csharp
public void CreateSectionView(IDrawingDoc drawing, string parentViewName)
{
    IModelDoc2 model = (IModelDoc2)drawing;
    
    // 1. Activate and select the parent view
    model.ClearSelection2(true);
    bool selectSuccess = model.Extension.SelectByID2(parentViewName, "DRAWINGVIEW", 0, 0, 0, false, 0, null, 0);
    
    if (!selectSuccess) return;
    
    // Activate the view to draw in its coordinate system
    drawing.ActivateView(parentViewName);

    // 2. Draw the section cut line in the active view's sketch
    // Note: coordinates must intersect model bounds in sheet scale
    ISketchManager sketchMgr = model.SketchManager;
    sketchMgr.AddToDB = true; // Draw directly to database
    
    // Draw vertical section line segment
    ISketchLine sectionLine = sketchMgr.CreateLine(0.1, 0.05, 0.0, 0.1, 0.25, 0.0) as ISketchLine;
    sketchMgr.AddToDB = false;

    if (sectionLine != null)
    {
        // 3. Select the section sketch line segment
        // Direct selection with Select4 is recommended
        IEntity lineEntity = (IEntity)sectionLine;
        model.ClearSelection2(true);
        lineEntity.Select4(false, null);

        // 4. Generate the section view
        // CreateSectionViewAt5 Parameters:
        // X, Y, Z - Placement coordinates of the new view on sheet
        // Label - View letter tag (e.g. "A")
        // Options - 0 for default (swCreateSectionViewAtOptions_e)
        // ExcludedComponents - Array of components to exclude from cut (assemblies only)
        // Depth - Slice depth (for partial sections)
        IView sectionView = drawing.CreateSectionViewAt5(
            0.25, 0.15, 0.0, // Placement coordinate
            "A",             // Section name tag
            0,               // Default option
            null,            // No components excluded
            0.0              // Full depth section
        );

        if (sectionView != null)
        {
            Console.WriteLine("Section View A-A successfully created.");
        }
    }
}
```

## 🔍 Creating Detail Views (CreateDetailViewAt4)

Detail views are generated by drawing a circular detail profile around a target location in the parent view.

```csharp
public void CreateDetailView(IDrawingDoc drawing, string parentViewName)
{
    IModelDoc2 model = (IModelDoc2)drawing;
    
    model.ClearSelection2(true);
    drawing.ActivateView(parentViewName);

    // 1. Draw a circular sketch profile representing the zoom boundary
    ISketchManager sketchMgr = model.SketchManager;
    sketchMgr.AddToDB = true;
    
    // Draw circle: CenterX, CenterY, CenterZ, Radius
    ISketchSegment circle = sketchMgr.CreateCircleByRadius(0.1, 0.15, 0.0, 0.015);
    sketchMgr.AddToDB = false;

    if (circle != null)
    {
        // 2. Select the circle segment
        IEntity circleEntity = (IEntity)circle;
        model.ClearSelection2(true);
        circleEntity.Select4(false, null);

        // 3. Generate detail view
        // Style: 0 (swDetailViewStyle_e.swDetailView_Standard)
        // ScaleNumerator / Denominator: scale ratio override (e.g. 2:1 zoom)
        // Label: "B"
        // Options: 0
        IView detailView = drawing.CreateDetailViewAt4(
            0.25, 0.28, 0.0, // Placement coordinates
            (int)swDetailViewStyle_e.swDetailView_Standard,
            2, 1,            // 2:1 Scale factor
            "B",             // Detail letter label
            0                // Options
        );

        if (detailView != null)
        {
            Console.WriteLine("Detail View B successfully created.");
        }
    }
}
```

## 🛠 View Placement Methods & Options Reference

### Section View Option Enums (`swCreateSectionViewAtOptions_e`):
*   `swCreateSectionView_Default` (0) — standard projection.
*   `swCreateSectionView_Partial` (1) — partial section view.
*   `swCreateSectionView_Aligned` (2) — aligned section cut.

### View Placement Methods:

| Method | Class | Description |
| :--- | :--- | :--- |
| `CreateDrawViewFromModelView3(...)` | `IDrawingDoc` | Inserts a base model view. |
| `CreateProjectedView2(X, Y, Z)` | `IDrawingDoc` | Creates a projected view from the active selected parent view. |
| `CreateSectionViewAt5(...)` | `IDrawingDoc` | Generates a section view from a selected sketch line. |
| `CreateDetailViewAt4(...)` | `IDrawingDoc` | Generates an enlarged detail view from a selected sketch circle. |
| `CreateAuxiliaryViewAt2(X, Y, Z, Label, Opts)`| `IDrawingDoc` | Generates an auxiliary projection from a selected straight edge. |

## ⚠️ Known Issues and Developer Rules

1.  **Sketch Coordinate Systems:**
    When drawing sketch entities (like the section line or detail circle) within an activated view, coordinates must align with the **view's internal sketch coordinate space**, not the overall sheet space. If your lines appear offset, check if the parent view scale has shifted the sketch origin.
2.  **Parent Selection Requirement:**
    Failure to pre-select the section sketch line or detail circle profile before calling `CreateSectionViewAt5` or `CreateDetailViewAt4` will cause the methods to return `null` without throwing exceptions. Ensure `Select4()` returns `true`.
3.  **View Clean-Up:**
    Disable sketch line visibility on drawing outputs if needed by toggling the construction line property on the segment: `ISketchSegment.ConstructionGeometry = true;`.
